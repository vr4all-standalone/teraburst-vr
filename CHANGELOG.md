# Teraburst VR v0.1.0

The first public VR4ALL release of Konami's Teraburst for **standalone Meta Quest 3/3S** and **Windows OpenXR**.

- Native stereo 3D world, adjustable depth/separation/world size and tracked guns.
- Scenery-aware lasers and physical 3D native reticles: **P1 blue / P2 red**.
- Native tutorial rifle plus Arcade/Zapper choices, automatic-fire recoil, smoke, flash and repeated haptics.
- Three-credit Start buttons, automatic RTC onboarding and explicit acknowledgement-driven P2 joining.
- Default paired layout **P1 left / P2 right**.
- Accepted FPS/audio improvements; temporary bottom FPS counters are **Off**, including existing preview installs. Saved controls/calibration remain.

## Downloads

- **Quest:** `teraburst-vr-quest.apk` — install and supply the owned `terabrst.zip` in Download.
- **PCVR:** `teraburst-vr-pcvr.zip` — extract, put `terabrst.zip` in `roms`, and run **Run Teraburst VR.cmd** with your OpenXR runtime selected.
- **Complete source:** `teraburst-vr-source.zip` — includes the port, pinned full MAME Git bundle, patches and dependency source snapshots.
- **SHA256SUMS.txt:** checksums for these exact downloads.

No game media is supplied; no CHD or separate BIOS is required. See the [project page](https://github.com/vr4all-standalone/teraburst-vr#readme) for setup, controls and licences.

Quest 3S gameplay is physically accepted by the user. Windows builds and OpenGL regression checks pass; a physical PCVR-headset test is pending. Complete routes/bosses are not exhaustively tested, upstream MAME incomplete-game/imperfect-sound flags remain, and leaning outside the arcade camera can reveal geometry gaps.

The named source asset is the complete buildable delivery; GitHub's automatic source ZIP contains the documentation page. Promotional banners are illustrations, not headset screenshots.
