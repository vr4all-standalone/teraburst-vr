# Teraburst VR promotional artwork

`readme-banner.png` is the wide project header; `release-card.png` is its companion release/social card. Both follow the existing VR4ALL header family: charcoal grid, bold white title, red VR badge, platform line and red/cyan accents.

Original reference: **Konami Teraburst US sales flyer (1998)**, preserved by [The Arcade Flyer Archive / International Arcade Museum](https://flyers.arcade-museum.com/videogames/show/1129), [direct scan](https://flyers.arcade-museum.com/videogame-flyers/1/teraburst-01129-01.jpg). Original characters, game artwork and trademarks remain Konami property. These are unofficial promotional adaptations, not a statement of endorsement or blanket asset licensing.

Created with the built-in image-generation tool. The original flyer and the existing CarnEvil VR4ALL header were supplied as art/style references; no extracted ROM/game assets were distributed. AI assistance recomposed the promotional illustration, so these images are **not gameplay/headset screenshots**.
